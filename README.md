# PawBox: Monthly Pet Subscription Box

A subscription box for dogs and cats with healthy treats, toys, and care products. This project demonstrates branding, landing page design, and marketing strategy development.

## Technologies Used
- Figma (mockups)
- HTML5, CSS3 (landing page)
- JavaScript (interactive elements)
- Canva (branding materials)

## Features
- Monthly subscription management
- Landing page with product showcase
- User-friendly subscription form
- Email notifications for new boxes

## Installation / Usage
1. Clone the repository:
2. https://github.com/valentinamaffeisjcc/pawbox-landing.git

3. 2. Open `index.html` in a browser
3. Explore the landing page and interactive features
